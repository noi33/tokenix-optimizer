# Tokenix Optimizer

![Tokenix Optimizer](preview.png)

Simple and real Windows PC Optimizer made in Python.

### Features
- Clean Temp Files
- Empty Recycle Bin
- Clear Thumbnail Cache
- Clear Windows Update Cache
- Disk Usage Info
- Startup Programs list
- Flush DNS Cache
- Browser Cache Info
- System Info (RAM, GPU, etc.)
- Top Memory Processes
- Network Info
- Optimize Drive (C:)
- Power Plans
- Disable Hibernation (free space)
- **Quick Optimize** (one-click safe clean)

### How to use
1. Download `TokenixOptimizer.exe`
2. Double-click it
3. Done

No Python needed.

### Requirements
- Windows 10 / 11

### Disclaimer
This tool only does safe & common maintenance tasks.  
Some options work better if you run it as Administrator.
